## Downloads

| File | For |
| --- | --- |
| `WizardWars-*-windows-x64.zip` | Windows 10/11 |
| `WizardWars-*-windows-x64-signed-runner.zip` | Windows PCs where **Smart App Control** blocks the normal build: the same game, started by the official signed Godot binary |
| `WizardWars-*-linux-x64.tar.gz` | Linux x86-64 |

Unpack and run `WizardWars.exe` / `WizardWars.x86_64`. Plays with **any webcam**
or an **Orbbec Gemini 2** depth camera; the game picks whichever is connected,
and Esc opens the settings. `HOW_TO_PLAY.md` inside the archive has the moves
and troubleshooting.
